# PVQC 化學字根｜圖文學習講義

2026-11-01 教師預覽草稿。新版入口為 `pilot.html`：四個代表課、541 詞共用查詢與6個概念延伸詞。原 `index.html` 的14主題草稿保留；尚未發布學生公開版。

代表課與來源比對狀態見 `STAGE2_REVIEW.md`。資料與介面檢查可執行 `node --test tests/shared-words.test.cjs`。

開啟 `index.html` 可檢視；也可使用一般靜態網站伺服器。沒有建置步驟。

## 功能

- 三組字根總覽、11 個圖文專題。
- 左右鍵／空白鍵翻頁；O 開啟總覽；F 全螢幕。
- 手機滑動翻頁、圖片分頁、點圖放大。
- 單字英文發音、全聽、停止、中文字義切換。
- 每課主動回想題與解答。
- 此瀏覽器的已學會標記；無帳號、無跨裝置同步、無學生資料上傳。

## 素材與來源

- 原始圖片保存在使用者指定的 Google Drive 正式素材庫，未修改。
- 此專案上傳網頁版圖片；`asset-inventory.csv` 留存原檔名稱、SHA-256、格式及尺寸。
- 教學文字依 Obsidian「PVQC 化學專業英文：字根詞彙教學庫 v3」及專案交接內容改寫；本草稿不是 541 字完整題庫。
- 參考介面：<https://mvcos-31-50-antigravity.netlify.app/student-deck>
- 參考介面只作操作與版面參照，程式另行製作。
- Noto Sans TC 為外部字型，連線不可用時使用裝置內建中文字型。
- 發音使用瀏覽器語音功能，實際聲音依裝置而異。
- 圖片與作者識別依原素材保留；未額外授予教材再散布授權。
